# Phase 07 — Consolidated Report

## Deliverable

**[`BIC-2026-001-blockchain-investigation-report.pdf`](BIC-2026-001-blockchain-investigation-report.pdf)** — 34 pages, 16 sections.

The consolidated report is the readable form of this investigation. The phase documents in this repository record *how* the work was done, decision by decision, as it happened; the report records *what was found* and what each finding is worth.

## Purpose of this phase

No new analysis was produced here. Every finding in the report already exists in Phases 00–06, and the phase documents remain the primary record — they carry the working detail, the intermediate reasoning, and the version-control history that evidences when each decision was made.

What the report adds is consolidation: a single document that can be read start to finish without navigating the repository, in which the fact / inference / attribution discipline is applied consistently across the whole investigation rather than phase by phase.

## Publication constraints observed

Fixed in Phase 00 and applied throughout:

- **Neutral, methodological title.** The subject of this study is the method, not the actor.
- **No attribution asserted.** Where published sources attribute the incident to a named actor, those statements are recorded as third-party claims and are not adopted as findings.
- **Nothing undocumented published.** Any address, pattern, or relationship surfaced that was not already present in public reporting would have been withheld and reviewed privately before any disclosure decision. No such material arose.
- **No natural person named or implicated.**

## A note on what the report does not claim

The trail documented carries approximately **0.11%** of the value that left the anchor address. The remaining 99.89% was not examined. No statement in the report about "the funds" applies beyond the single path recorded in Section 7 — a boundary stated in the executive summary, restated at the end of the trace, and carried into the conclusions, because it governs the weight of everything else in the document.
