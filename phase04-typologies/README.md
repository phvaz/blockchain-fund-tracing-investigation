# Phase 04 — Typology Identification

**Status:** `[ ] Not started  [ ] In progress  [ ] Complete`

## Objective

Map the movement patterns observed in Phase 03 to catalogued laundering typologies, with sources.

## Method

Two rules govern this phase (see `methodology/analytic-standards.md`, Section 4):

1. **The pattern is observed before it is named.** Document what the transactions show → identify the pattern → look up whether it is catalogued → cite the source. Never the reverse.
2. **Naming a typology is an inference, not a fact.** That funds passed through a service is a fact. That the purpose was layering is an interpretation, rated accordingly.

## Note on prior knowledge

This is a learning area for the analyst. Typologies are researched and cited as encountered rather than applied from existing expertise. Sources are recorded for each so the reader can verify the classification independently.
